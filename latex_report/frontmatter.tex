\begin{center}
    {\Large \bfseries \color{krmunavy} ABSTRACT}\\[0.8cm]
\end{center}

\noindent In contemporary competitive electronic sports (esports), title-specific community feedback serves as a mission-critical barometer for patch balance, tactical meta evolution, and player retention. Riot Games' tactical first-person shooter \textit{Valorant} generates millions of conversational interactions monthly across Reddit, Steam Community forums, Discord servers, and Twitter. However, existing commercial esports analytics platforms (e.g., VLR.gg, Tracker.gg) concentrate exclusively on quantitative match telemetries (such as Kill/Death/Assist ratios and combat scores), completely omitting unstructured natural language player sentiment and subjective gameplay perception. Conversely, conventional off-the-shelf Natural Language Processing (NLP) sentiment classifiers fail catastrophically when applied to competitive gaming corpora due to highly specialized jargon, non-standard punctuation, syntactic gaming slang (\textit{e.g.}, ``diff'', ``clutch'', ``nerf'', ``lineup'', ``whiff'', ``instalock''), and sarcasm.

\vspace{0.4cm}
\noindent To resolve this dual failure mode, this project introduces \textbf{Valosent AI}, an enterprise-grade, publication-quality, multi-tier hybrid sentiment intelligence and tactical analytics platform engineered specifically for the \textit{Valorant} gaming ecosystem. The system synthesizes and sanitizes a stratified corpus of 102,209 authentic player reviews spanning 24 playable Agents and 13 competitive maps. The algorithmic architecture is structured as a tiered inference cascade: Tier-1 deploys a sub-linear TF-IDF vectorizer coupled with a calibrated Linear Support Vector Classifier (LinearSVC, 91.2\% test accuracy, 4.2\,ms inference latency); Tier-2 incorporates a Multinomial Naive Bayes probabilistic model (87.4\% accuracy, 1.8\,ms latency); Tier-3 leverages a fine-tuned \textit{DistilBERT-base-uncased} contextual transformer (93.8\% accuracy, 44.6\,ms latency); and Tier-4 integrates an explainable Large Language Model (LLM) reasoning fallback for complex idiomatic edge cases.

\vspace{0.4cm}
\noindent The production software implementation is built on Python 3.10+, Flask, PyTorch, Hugging Face Transformers, and Scikit-Learn, accompanied by a dual-persistence storage layer (local SQLite via SQLAlchemy ORM alongside remote PostgreSQL via Supabase) and zero-trust authentication via Google OAuth 2.0 and SMTP-backed Gmail OTP verification. Real-time Explainable AI (XAI) token saliency attribution highlights emerald-green positive and crimson negative lexical drivers directly inside an interactive cyberpunk-themed Tactical HUD. Comprehensive benchmark evaluations demonstrate that the hybrid ensemble achieves a peak macro F1-score of 94.6\% with negligible resource footprints (under 480\,MB RAM), proving its viability for live studio operations and competitive tournament intelligence.

\vspace{0.8cm}
\noindent \textbf{Keywords:} Sentiment Analysis, Valorant, Esports Analytics, DistilBERT, Support Vector Machines, Naive Bayes, Explainable AI (XAI), Large Language Models, Multi-Tier Inference Cascade.
