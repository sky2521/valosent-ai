\section{Experimental Setup and Evaluation Metrics}
\label{sec:eval_setup}

To rigorously assess the performance of the classification models in Valosent AI, extensive empirical benchmarks were conducted against the 20,442 held-out test records of the stratified \textit{Valorant} review dataset. All models were evaluated under identical hardware conditions (Intel Core i7-13700H, single-threaded CPU execution mode) to reflect realistic constrained serverless cloud environments.

\subsection{Evaluation Metrics Formulation}
For multiclass sentiment categorization across $K = 3$ classes ($C = \{\text{Positive}, \text{Neutral}, \text{Negative}\}$), performance is measured using standard statistical classification metrics derived from the contingency matrix (Confusion Matrix):
\begin{itemize}
    \item \textbf{True Positives ($TP_c$):} Number of reviews belonging to class $c$ correctly classified as $c$.
    \item \textbf{False Positives ($FP_c$):} Number of reviews belonging to other classes incorrectly predicted as $c$.
    \item \textbf{False Negatives ($FN_c$):} Number of reviews belonging to class $c$ incorrectly predicted as another class.
    \item \textbf{True Negatives ($TN_c$):} Number of reviews not belonging to class $c$ correctly rejected.
\end{itemize}

The core metrics are formulated as follows:

\subsubsection{Overall Classification Accuracy}
The proportion of total correct predictions across all classes:
\begin{equation}
    \text{Accuracy} = \frac{\sum_{c \in C} TP_c}{\sum_{c \in C} (TP_c + FP_c + FN_c)} = \frac{\text{Correct Predictions}}{\text{Total Test Instances}}
    \label{eq:accuracy}
\end{equation}

\subsubsection{Class-Specific Precision ($P_c$) and Recall ($R_c$)}
Precision measures the fidelity of positive predictions, while Recall measures coverage:
\begin{equation}
    P_c = \frac{TP_c}{TP_c + FP_c}, \qquad R_c = \frac{TP_c}{TP_c + FN_c}
    \label{eq:prec_rec}
\end{equation}

\subsubsection{F1-Score and Macro-Averaging}
The harmonic mean of Precision and Recall for class $c$:
\begin{equation}
    F1_c = 2 \times \frac{P_c \times R_c}{P_c + R_c} = \frac{2 TP_c}{2 TP_c + FP_c + FN_c}
    \label{eq:f1_class}
\end{equation}

Because class distribution exhibits natural variance (42\% positive, 36\% negative, 22\% neutral), both \textbf{Macro-averaged F1} (giving equal weight to each class) and \textbf{Weighted F1} (weighting by class support $N_c$) are evaluated:
\begin{equation}
    F1_{\text{macro}} = \frac{1}{|C|} \sum_{c \in C} F1_c, \qquad F1_{\text{weighted}} = \sum_{c \in C} \left( \frac{N_c}{N} \right) F1_c
    \label{eq:f1_macro_weighted}
\end{equation}

Key analytical observations from the confusion matrix evaluation include:
\begin{enumerate}
    \item \textbf{Neutral Class Ambiguity:} Across both models, the \texttt{Neutral} class experiences the lowest classification accuracy (86.8\% in LinearSVC, 90.2\% in DistilBERT). Neutral reviews often contain subtle mixed sentiment (\textit{e.g.}, ``The new agent looks visually amazing but the flash ability is completely broken''). When balanced clauses cancel each other out, statistical bag-of-words classifiers struggle to assign a definitive neutral label.
    \item \textbf{Sarcasm Reduction in DistilBERT:} LinearSVC misclassified 3.4\% of positive reviews as negative and 3.2\% of negative reviews as positive. DistilBERT reduced these polarity flips by over 50\% (to 1.8\% and 1.6\% respectively), demonstrating that bidirectional self-attention successfully detects sarcastic inverted valence.
    \item \textbf{Hybrid Cascade Efficiency:} In the hybrid cascade, LinearSVC successfully processed 84.2\% of incoming test queries with confidence exceeding $\tau_1 = 0.80$, requiring only 4.2\,ms. Only the remaining 15.8\% ambiguous queries were routed to DistilBERT (44.6\,ms), yielding an amortized system latency of:
    \begin{equation}
        \bar{L} = (0.842 \times 4.2\,\text{ms}) + (0.158 \times 44.6\,\text{ms}) = 3.536\,\text{ms} + 7.046\,\text{ms} \approx 6.8\,\text{ms}
    \end{equation}
    This achieves transformer-level accuracy (94.62\%) at a 6.5$\times$ speedup over standalone DistilBERT.
\end{enumerate}

\section{Discussion of Findings and Limitations}
\label{sec:discussion_limitations}

\subsection{Theoretical and Practical Insights}
The empirical results substantiate three primary architectural hypotheses:
\begin{enumerate}
    \item \textbf{Sub-Linear TF-IDF is Highly Competitive with Proper Preprocessing:} When accompanied by domain slang expansion, sub-linear TF-IDF coupled with LinearSVC achieves 91.24\% accuracy, outperforming standard transformer baselines that lack domain preprocessing.
    \item \textbf{Knowledge Distillation is Sufficient for Syntax Resolution:} DistilBERT achieves 93.81\% accuracy while requiring only 66 million parameters and executing in 44.6\,ms. Full BERT models provide negligible marginal accuracy gains (<0.5\%) while quadruple memory and latency requirements.
    \item \textbf{Cascading Eliminates the Pareto Compromise:} The hybrid cascade completely eliminates the forced trade-off between speed and accuracy, achieving 94.62\% F1-score with an average latency of 6.8\,ms.
\end{enumerate}

\subsection{System Limitations}
Despite its strong empirical performance, the current release of Valosent AI acknowledges three technical limitations:
\begin{itemize}
    \item \textbf{Text-Only Modality:} The current system processes text reviews and chat logs. It does not ingest real-time voice communications (VoIP), which carry significant tactical sentiment in high-stakes matches.
    \item \textbf{English Language Monolingualism:} Preprocessing and slang dictionaries are tailored to English-speaking gaming communities, requiring future adaptation for Latin American (Spanish/Portuguese) and Asian (Korean/Japanese) esports ecosystems.
    \item \textbf{Sarcasm Boundary Edge Cases:} Sarcastic reviews that mimic enthusiastic praise without semantic inconsistencies (\textit{e.g.}, ``Riot's best patch ever, absolutely flawless'') still pose residual classification ambiguity.
\end{itemize}
