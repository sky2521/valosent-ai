04

TACTICAL & DRAFT ENGINE

Wilson 95% LB & 5v5 Predictor

Prevents small-sample flukes from dominating rankings by sorting map picks, team compositions, and teammate synergies by the 95% Wilson score lower bound (minimum 20 picks).

  • Side Rankings: Attack (T) and Defense (CT) recommendations rank by median side ACS percentile.
  • Match Outcome ML: Pre-match Logistic Regression trained on map, patch, agent indicators, and role counts across 31,294 resolved maps (51.91% acc / 51.88% Macro F1 vs 35.47% baseline Macro F1).
  • Zero Leakage: Post-match scores, ACS, K/D, KAST, ADR, and ratings are strictly excluded from match features.
05

PLATFORM ENGINEERING

Auth, Persistence & Official Art

  • Database (valosent.db): Persistent SQLite via Flask-SQLAlchemy with relational User, OTPCode, and Review tables.
  • Multi-Factor Auth: Google OAuth 2.0 via Authlib, passwordless 6-digit Gmail OTP via smtplib (hashed, single-use, 5-min TTL), and salted password hashing.
  • Official Assets: High-res agent icons, full-body portraits, role emblems, and all 13 map splash wallpapers cached from valorant-api.com with local SVG fallbacks.
  • Memory Optimization: Columnar Parquet projection & streaming aggregations keep cloud memory footprint under 220 MB.
!

LIMITATIONS & ETHICS

Interpret responsibly

  • Proxy Sentiment Labels: Review labels come from score thresholds rather than human annotation, and the Neutral class remains the smallest class (458 held-out test examples).
  • Historical Expansion: The 2023–2026 agent/map expansion supplements the April 2021–April 2023 VLR.gg snapshot to provide full 30-agent / 13-map coverage; there is no live Riot API match feed.
  • Descriptive, Not Causal: Recommendations and pair win rates reflect historical co-occurrence; missing event IDs, regions, and player skill prevent causal win claims.
  • Heuristic Aspect Polarity: Agent/map mention sentiment uses a transparent local-clause lexicon rule engine rather than a trained ABSA neural model.
